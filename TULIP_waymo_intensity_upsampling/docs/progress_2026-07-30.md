# TULIP Waymo Intensity Upsampling 進捗（2026-07-30）

## 目的

Waymo TOP LiDARの距離・反射強度をTULIPでアップサンプリングし、将来は清水研究の
静的点群地図・画像照合パイプラインへ接続して自己位置推定への効果を評価する。

## 完了した作業

### 前処理仕様の分離

TULIP用の単一フレームRange Imageと、清水研究の時系列重畳・動的物体除去・
カメラ投影後の成果物を混同しない設計にした。TULIPの教師値は加工前の物理量とし、
64ラインTOP LiDARの偶数ring `[0,2,...,62]` を32ラインGTに採用した。

### 64ライン・32ライン抽出

1フレームから以下を同時保存できる。

- `range_64`, `intensity_64`, `valid_mask_64`
- `range_32`, `intensity_32`, `valid_mask_32`
- `ring_ids_32`
- context、frame index、timestamp、統計量を含むmetadata

引き継ぎ対象の代表フレームで確認した実測値:

- native shape: `[64, 2650, 4]`
- 32ラインshape: `[32, 2650]`
- valid pixels: 64ライン `152,616`、32ライン `76,240`
- range median: 64ライン約`19.86 m`、32ライン約`19.98 m`
- intensity median: 64ライン約`0.162`、32ライン約`0.149`
- intensity max: `11072`（外れ値対策が今後必要）

### 引き継ぎmanifestの正規化

評価GT `manifest_cross_eval_gt_v3.csv` は同じクエリフレームがanchorごとに
繰り返される。`(q_subset, q_seg, q_frame_index)` で集約した結果:

- 入力GT pair: `16,963`
- 一意なWaymoフレーム: `881`
- 元TFRecord欠損: `0`

カメラJSONから `frame_timestamp_micros` を取得し、古い `/mnt/d` パスを現在の
`/mnt/w/32line` へ解決した。同じJSONをキャッシュし、1,000行ごとに進捗表示する。

### テストとGit

ring対応、shape、manifest重複、パス置換、timestamp競合、TFRecord欠損を
実データなしの単体テストで確認した。manifest実装は次のコミットとしてpush済み。

- `1cdbc79 Add inherited Waymo frame manifest builders`
- `5bf1485 Show progress while building Shimizu frame manifest`

## 工夫した点

1. segment単位を保ち、将来のデータ分割で同一走行のリークを防げるようにした。
2. frame identityをsegment・index・timestampの三点で照合する。
3. TensorFlow/Waymo依存を遅延importし、dry-runと単体テストを軽量環境で動かす。
4. `--max-frames` で1件から段階的に拡大できるようにする。
5. `--resume` はNPZとmetadataが揃いidentityも一致した場合だけスキップする。
6. 一時ファイルから置換する原子的保存で中断時の半端な成果物を避ける。
7. TFRecordをフレームごとに開かず、segmentごとに1回走査する。
8. エラーを `failures.csv` に残し、全体の再実行を容易にする。

## 5フレーム検証後に追加した機能

5フレームの抽出、resume、欠損0件を確認し、監査と16ライン生成を追加した。

```bash
source /home/wakamatsu/ITS/.venv_tulip/bin/activate
bash scripts/50_audit_and_prepare_shimizu_16_32.sh \
  --max-frames 5 --prepare-16 --resume
```

監査は64/32のshape、dtype、偶数ringの完全一致、NaN/Inf、metadata identityを
確認する。16ライン入力は32ラインGTの1行おきから作り、元64ライン基準では
ring `[0,4,...,60]` となる。抽出対象がresumeですべて完了済みの場合は
TensorFlow/Waymo SDKを初期化せず終了する。

5フレームの実監査結果:

- audited: `5/5`
- failed: `0`
- 16→32ペア生成: `5`
- intensity最大値: `19712`
- フレーム別p99.5の最大: 約`0.988`

最大値とp99.5の差が大きいため、学習前に外れ値方針を固定する必要がある。
