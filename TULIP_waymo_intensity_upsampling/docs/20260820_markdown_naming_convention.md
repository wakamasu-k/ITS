# Markdownファイルの日付管理方針

今後新しく作成するMarkdownファイルは、ファイル名の先頭に作成日を付ける。

```text
YYYYMMDD_内容.md
```

例:

```text
20260820_pointcloud_evaluation.md
```

既存のMarkdownファイルは、既存参照を壊さないためファイル名を変更せず、末尾に次の形式で日付を記録する。

```text
作成日（ファイル更新日時から推定）: YYYY-MM-DD
```

Gitの作成履歴がないファイルについては、正確な作成日時ではなくファイルシステムの更新日時を記録する。
